## 能力边界与待接入字段

- 五阶段没有关联执行记录。仅视频资料及当前模型尝试可反映已有记录，其余显示未测；阶段入口导航至现有页面，不虚构完整工作流。
- 现有成果是 Markdown 文本，没有标准化逐镜字段。保留可编辑原文，不凭猜测解析成通过检查的分镜表。缺少 `shots`、逐镜素材依赖、检查结果与输入版本关联，因此逐镜检查、缺字段定位和质量评审仍待接入。
- 现有服务要求商品名称、目标人群、事实及视频画面；保留此校验契约。尚不能改成仅账号/目标/业务资料三项，也不能仅凭逐字稿生成。
- 不支持独立选择采样画面、提取字幕或本地 ASR；明确显示实际读取范围与人工逐字稿无时间轴。
- 未提供五层探针报告、接口验证版本、日期与样本范围，显示未测和占位。现有目标接口单次执行前还会查询价格和额度，不能承诺总网络请求上界为 1；没有新增自动探针按钮。
- Key 没有末四位字段，前端不读取完整密钥来截取；以已配置/未配置代替。保存方式依真实 DPAPI 状态展示。
- 备份日期和数据绝对目录没有现有展示字段，保留占位。诊断比较和趋势阈值没有配置，暂不输出结论或虚构最低样本数。

这些能力需要单独确认后端范围，不能计为本次已完成能力。
