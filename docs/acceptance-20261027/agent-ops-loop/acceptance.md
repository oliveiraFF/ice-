## 已实现

- 运营总览 `/ops-wallboard` 中增加隔离流程面板，保持 11 项导航和全软件主题。仅显式开启 `ICE_AGENT_LOOP_TEST=1` 的隔离实例显示操作。

- 资料诊断引用冻结资料与哈希。未提供表现数据、未确定表现门槛时，只给资料缺口，不输出表现结论。
- 选题保留任务型原始证据、观察日期、策略版本；参考标题不冒充需求或自有经营表现。
- TikHub/DeepSeek 预先持久占用预算，跨进程排他账本锁、阶段请求防重复。失败/超时不释放占用，不自动重试。

- 测试稿禁止登记为真实发布。未发布分支缺指标时 `insufficient`；明确标注的合成反馈只生成隔离演练复盘，不写正式复盘表、不改策略。
