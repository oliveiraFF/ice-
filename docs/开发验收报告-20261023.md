## 完成的修复

1. 修复 3 个任务 API 测试的共同阻塞：夹具头像缺少 JPEG 结束标记。改用可解码小 JPEG，保留生产图片校验，并关闭 HTTPError 响应避免资源泄漏。
2. 保留账号 UID、策略、规则、输入、素材、结果与不可变版本；冻结规则实际用于对应生成，手工修改不改写旧版本。
3. 原始模型 HTTP 响应先保存为本地 BLOB，再解码和校验。只允许去 BOM 和完整外层代码围栏，记录修复；多对象、重复字段、非有限数值拒绝。格式错误保留错误位置。
4. 生成尝试分开记录 processing、success、validation_failed、result_unconfirmed、failed。处理中断重开标为结果未确认；失败保留旧成果，不自动调用第二次模型。超大响应仅保存已读取的前 524289 字节并拒绝采用。
5. 确认、版本及并发门禁防止重复生成；手动重新生成可以保存新版本。每次视频分析输出上限设为 6000 tokens，费用仍需另行明确。
6. 导出包含账号 UID、策略快照、素材摘要、台词来源、采样时间、规则版本与哈希；未保存的编辑明确标注。采样 JPEG 与原始响应不进入 Markdown。
7. 更换素材按文件哈希识别：即使所有输入和采样帧相同，仍创建新输入版本，不沿用旧结果。非空台词不得标成“无来源”。
8. SQLite 迁移前一致性备份，检查完整性及各表记录数量，另存旧结构版本、SHA256 和恢复范围说明。备份失败阻止迁移；只增加表，迁移中断能回滚。
9. 源码打包白名单包含 agent_tasks.py，生成的源码包独立启动通过。
