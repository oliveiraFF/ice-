# ice运营台 · Apple Silicon 测试版

适用于 M 系列 Mac，首版构建目标为 macOS 14 或更高版本；不支持 Intel。
最终支持范围以实际构建与运行验收报告为准，不能仅凭生成 DMG 宣称验证完成。

打开 DMG，把 ice运营台.app 拖入 Applications（应用程序），再从应用程序启动。
用户无需安装 Python 或 Node.js。此版仅采用临时签名（ad-hoc），没有 Apple Developer ID 签名或公证，系统可能阻止首次打开；不应作为已公证的客户正式发行版。

资料默认保存在 `~/Library/Application Support/ICEOps/data/`，视频缓存保存在同级 `downloads/`。
升级前退出旧版本并备份该 ICEOps 文件夹。替换或移除应用本身不会清除这里的数据。
新客户在账号资料表单填写账号名称、内容方向和目标人群，由软件初始化工作区，无需自己建立空文件夹。

TikHub 密钥由当前 Mac 用户的系统钥匙串保存，本地凭据文件只记录随机标识，不记录密钥。
系统可能要求批准钥匙串访问；拒绝或钥匙串锁定时软件报错，不回退明文保存。
Windows 的 DPAPI 凭据不能在 Mac 解密，换电脑或系统账户后须重新配置；安装包不附送密钥、额度或私人账号资料。

本地字幕需要另行安装适用于 Apple Silicon 的 ffmpeg、whisper-cli 及 Whisper .bin 模型，填写实际完整路径。
Windows 的 .exe 不能用作 Mac 字幕程序。未安装本地引擎时可粘贴逐字稿继续。
模型和视频生成服务需自行配置。真实在线调用仍受软件中的预算和手动确认限制。

GitHub 云端构建、离线技术验证不代表真实平台抓取、模型内容质量或经营效果已经通过验收。
