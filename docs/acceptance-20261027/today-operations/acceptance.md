# 今日运营界面验收

日期：2026-10-27。依据：用户提供的「今日运营」截图及已确认的实施范围。分支：feat/ui-today-operations。

## 实现

- 将原先五个等宽指标卡改为橙色今日重点、上下堆叠的周产出/待处理指标、跨两行的项目列表；下方为七日柱形图、内容结构状态和全宽最近动态表。
- 保留原有 11 项导航；账号、策略、当前视频任务与成果收在「账号、策略与创作详情」中；原数据与运营明细仍可展开。
- 今日重点取当前运营动作与最近一份非演示运营建议的未完成动作。本周产出与七日图只统计本机非模拟发布登记，按业务时区转换发布时间，并按平台/作品 ID 去重。
- 项目列出未完成内容任务及最近四条视频任务中尚无结果的任务；已发布内容任务和已有成果的视频任务不冒充进行中。
- 当前数据结构没有口播、产品、探店等分类字段，内容结构环显示「分类待接入」。不复制参考图中的演示数字、增长率、目标进度或分类占比。
- 读取失败显示错误并保留上次成功数据；刷新可恢复。没有新增后端、数据库结构、第三方依赖或收费调用。

## 验证

- 实际启动本地 app.py，真实 Chrome/Playwright 覆盖 320、375、390、414、768、1280 宽度。总览及原视频工作流均无页面级横向溢出，11 项导航可点击。
- 1280 桌面验证重点卡/指标/项目三列、项目跨两行、动态表全宽；390 窄屏改为堆叠布局、动态表转为带标签的记录行。
- 本机接口读取失败的注入验证：显示失败提示，保留旧统计，恢复后重新读取成功。该注入仅模拟读取失败。
- 有数据流程使用全新的临时数据库，由 OpsStore 实际保存明确命名为「【合成验收】」的稿件、任务和发布登记。页面读取真实本地接口，显示 1 篇周产出、1 项待补内容任务、1 根由记录计算的柱形；已发布任务不进入进行中，动态链接能打开实际保存稿件。
- 合成测试只验证技术显示与跳转，未写入用户数据，不代表真实经营表现或模型质量。
- 汇总逻辑测试覆盖平台/作品 ID 去重、时区跨日、未知发布时间、模拟记录排除与未完成动作。
- Python 回归：40 项，36 通过、4 项因未提供获批只读 SHORT_VIDEO_OPS_TEMPLATE 而跳过。
- JS 语法及 diff 空白检查通过；finesse 检测 P0=0。旧样式的 P2 颜色常量提示保留，本轮新增样式使用命名 token。
- 浏览器全部请求限于本机，0 个 JS 错误，没有模型生成、转写或 TikHub 收费请求。
