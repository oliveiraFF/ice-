## 真实 UI 流程

1. 空态显示“用示例试一下”；点击后填入标注为合成的主题和资料，并保持“演示试跑”模式。
2. 从页面生成演示版 v1，再从 v1 建立演示优化版 v2；保存后刷新页面，v2 与两条历史版本仍可恢复。
3. 修改表单后切换旧版本会出现覆盖确认；确认后页面恢复所选版本及其冻结输入。
4. 选择超过 12 条附加参考资料时，第 13 条不会加入；移除痛点、参考资料或材料标签后，复选状态和数量同步更新。
