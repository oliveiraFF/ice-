# ice运营台 owner 源码内测包

- 需要 Python 3.6 或更高版本；本次验证的精确版本见外部交付报告。使用标准库，以浏览器运行，不是免安装 exe，也不是桌面壳分发包。
- 双击 启动.bat；或用 Python 执行本目录 app.py。默认端口 8765；占用时可指定 --port 其他端口。服务只接受本机访问。
- /、/tools、/creative、/dashboard、/script 保留；使用说明以页面能力为准。
- 当前窗口按 Ctrl+C 停止服务，停止后再备份。运行数据在 data/，视频缓存下载在 downloads/，浏览器导出由用户选择保存位置。不要在程序写入时直接复制正在运行的数据库。
- 发布包从 _ops 加载工作流，不需要开发机 D/E 盘目录。不要设置指向其他项目的 OPS_PROJECT_ROOT；此变量仅供开发时显式覆盖。
- 新 data/ 不含私人数据库。应用自带的 demo 与用户导入的 live 数据隔离；脚本页默认用雷达 live 作品，无匹配会阻断；示例模式需要主动选择。
- 模型设置中填写服务地址、模型名和密钥；密钥只在内存，重启需重填。包不读取或携带开发机 .env。测试模式不调用模型。
- 真实模型需要已有 owner 付费许可、服务进程 LLM_ALLOW_PAID=1 和页面本次确认；保存模型配置不发送请求。不自动重试。当前包的验证没有付费请求。
- 运营工作台、运营建议、研究稿、成片审阅与咨询记录已在本包提供；已保存的建议/稿件/审阅记录重启后保留，未保存的表单需及时导出。
- 列表/详情只返回范围元数据与摘要，不回传采样图；历史记录恢复文字与关联版本，不恢复原视频。
- 真实模型调用需服务进程 LLM_ALLOW_PAID=1 的独立付费许可；页面本次确认不能替代，软件不会自动开启。
- MANIFEST.sha256 校验分发文件（不含清单自身）；SOURCE.json 记录源码来源。运行后产生的数据不属于原分发清单。customer/免安装包尚未在本批验收。
