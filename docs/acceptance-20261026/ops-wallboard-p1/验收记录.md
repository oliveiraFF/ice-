## Pre-flight 自评

1. 数据是否真实来源于 Agent workspace，而不是假设出的业务统计？页面读取固定文件白名单；无资料为 `null`，仅显式输入零才显示 `0`；截图中的模板数据明确标了合成。
2. 设计是否仍像 ICE 而非套用通用 AI 看板？截图保留 ICE 11 项图标侧栏和灰绿表面，主面板按目标运营链路排布，不新增照片或图表样板。
3. 空态、异常和迟到数据是否可区分？浏览器分别验证了未生成资料、首屏离线、刷新失败和显式空异常清单；失败后原数据 DOM 保留。
4. 移动端是否可读、可点且无页面级横向溢出？320–414 宽度均无溢出；刷新/全屏按钮和流水线整卡链接至少 44px，点击导航已通过。
5. 页面是否只读且不产生付费请求？wallboard 捕获的请求均为本机 GET；离线、空态与合成数据验收只使用临时目录，模型配置未连接，未调用 TikHub 或模型服务。
