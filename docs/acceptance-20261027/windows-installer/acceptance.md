# Windows 安装程序

用户确认：默认安装到当前用户目录，创建快捷方式和卸载入口，卸载保留用户数据，不打包个人workspace、实跑数据库或密钥。本次只增加安装器构建，不改变软件业务行为。

## 安装行为

- Windows 10/11 x64；默认 `%LOCALAPPDATA%\Programs\ICEOps`，只写当前用户注册表，不请求管理员权限。
- 中文安装向导，桌面与开始菜单快捷方式，Windows“已安装的应用”卸载入口。
- 程序数据在安装目录的 `data`，下载在 `downloads`。升级保留数据；卸载逐项删除已打包程序文件，只尝试移除空目录，保留数据库、配置、下载、workspace和用户另存文件。
- 运行中安装/升级或卸载会拒绝继续，不自动结束进程。
- 不迁移或覆盖现有便携版、正式账号workspace和正在使用的安装包。首次安装为干净数据目录；原便携版数据仍在原位置。
- 依赖电脑已有的 Microsoft Edge WebView2 及 .NET Framework 4.6.2或兼容版本，不自动下载系统组件。离线ASR引擎和模型需在软件中选择本机路径，不将本机私有配置、模型和密钥预装进安装包。

## 可复现构建

应用来自已推送main `749848e760ea09f0682a45231eaa18a3fb0accec`，干净构建，270项分发哈希及173项构建输入已核验。payload包含MANIFEST本身共271文件，程序必需的公开演示资源保留；本次个人测试资料不打包。

使用[NSIS官方3.13](https://nsis.sourceforge.io/Download)便携编译器，下载ZIP与[官方项目公开SHA256](https://sourceforge.net/projects/nsis/files/NSIS%203/3.13/nsis-3.13.zip/download)一致：`ba63dffc4410ee89193e1cb5a41989991bd77c61068da17e3156d136b7b0b3d8`。编译器仅解压到本机独立构建目录，不安装为系统依赖。

```powershell
python build_installer.py --release <已校验的桌面发布目录> --compiler <NSIS目录/makensis.exe> --output <新的Setup.exe>
```

构建器拒绝脏源码发布、清单越界、修改后的文件、额外文件、数据库、私有数据目录或凭据文件；卸载清单由已校验的逐文件清单生成，不使用递归删除或通配符删除。
